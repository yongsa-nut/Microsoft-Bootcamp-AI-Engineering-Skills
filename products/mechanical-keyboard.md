# TypeForce TKL Mechanical Keyboard

## Product Overview

Product Name: Contoso TypeForce TKL Mechanical Keyboard
Product SKU: EL-TFT-BLK (Black), EL-TFT-WHT (White)
Category: Electronics
Product Description:
The Contoso TypeForce TKL is an 87-key tenkeyless mechanical keyboard combining hot-swappable Gateron switches with dual-mode connectivity for desktop and wireless use. Per-key RGB backlighting, PBT doubleshot keycaps, and a Windows/Mac layout toggle make it a versatile option for professionals and enthusiasts. The current version (v1.2) includes Bluetooth 5.2 wireless and hot-swap switch support — features not present in the original v1.0 release.

## Key Features

- **Hot-Swappable Switches**: Swap Gateron switches without soldering; 3-pin and 5-pin compatible
- **Dual-Mode Connectivity**: USB-C wired and Bluetooth 5.2 wireless; switch seamlessly between modes
- **Per-Key RGB**: Individual key RGB backlighting with customizable profiles via Contoso software
- **PBT Doubleshot Keycaps**: Durable keycaps with legends that will not fade or shine with extended use
- **Windows/Mac Toggle**: Hardware switch on the underside remaps modifier keys for macOS layout
- **87-Key TKL Layout**: Full functionality without the numpad; saves desk space
- **Multi-Device Bluetooth**: Pair up to 3 devices via Bluetooth, switch with Fn+1/2/3
- **USB-C Detachable Cable**: Braided USB-C cable included; replaceable with any USB-C cable

## Known Issues & Limitations

- Bluetooth latency is approximately 2–4ms higher than wired mode; imperceptible for typing but may be noticeable for competitive gaming
- RGB backlighting reduces wireless battery life significantly; expect 20–30h with RGB on vs 72h with RGB off
- The Mac layout toggle remaps standard modifier keys only; some Mac-specific media keys require software configuration
- Hot-swap sockets may loosen over many switch cycles; Contoso recommends limiting hot-swaps to avoid socket fatigue

## Frequently Asked Questions

Q: What is different between the original v1.0 and the current version?
A: The original v1.0 (released at $109.99) was wired-only via USB-C and did not support hot-swappable switches. Version 1.1 introduced Bluetooth 5.2 wireless connectivity and hot-swappable switch sockets, and raised the price to $139.99. Version 1.2 added a Mac key layout toggle. If you own a v1.0 unit, these features cannot be added via firmware — they require hardware changes present only in current production units.

Q: Can I use third-party switches with the hot-swap sockets?
A: Yes, with conditions. The PCB supports 3-pin and 5-pin MX-style switches from any manufacturer. Switches with non-standard pin configurations or optical switches are not compatible. Contoso recommends Gateron or Cherry MX series switches for the best socket fit and longevity.

Q: Does Bluetooth mode work while the keyboard is charging via USB-C?
A: Yes. You can charge via USB-C and use Bluetooth simultaneously. Note that when the USB-C cable is connected, the keyboard does not automatically switch to wired mode — you must press Fn+W to toggle between wired and wireless modes manually.
